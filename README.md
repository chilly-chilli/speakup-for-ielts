# SpeakUp for IELTS Speaking Practice

SpeakUp 是一个面向 ChatGPT 的雅思口语练习站点和 MCP 服务。它提供私人题库、模拟考试与练习记录，帮助使用者在语音对话中练习并回顾自己的回答。

## 让 ChatGPT 为你部署

使用具备 **Sites 创建、发布及插件连接能力**的 ChatGPT 或 Codex，提供本仓库地址，并复制以下提示词：

> 请阅读这个仓库的 README.md 和 AGENTS.md，使用仓库源码在我的账号下创建一个新的、仅本人可访问的 ChatGPT Site，并完成数据库配置、构建、测试和发布。使用 Sites 为该站点自动生成的 MCP 插件，完成连接，并验证站点、`/mcp` 的 `server/discover` 和 `tools/list`。不要复用原作者的站点、插件、数据库或身份信息。完成后告诉我实际站点和插件入口、验证结果以及尚未验证的功能。

部署依赖使用者账号和当前产品环境具备相应能力；仅让普通聊天模型读取代码并不能保证它具有创建或发布权限。站点和插件保持私有，不会自动导入原站点的个人数据。

## 功能

- 完整模拟考试或单独练习 Part 1、2、3；可选择严格模式或辅助练习。
- 默认使用题库题目；可选择允许生成 Part 3 追问。
- 导入私人题库，预览并核对后启用；网页接受 Markdown 或 TXT，PDF、Word 可先交给 ChatGPT 提取。
- 保存练习、回答与诊断报告，跨对话回顾；网页提供手动计时器。
- 按可用证据提供反馈。分数是未经验证的练习估计，不是官方 IELTS 成绩；仅凭文字不能评估发音或声音表现，计时也需要使用者自行操作。

内置题库来自新航道国际教育集团教学与考试研究院的材料，源码记录了产品负责人对公开分发的授权；文字由 OCR 导入，仍需编辑核对，不是官方 IELTS 试卷。使用者亦可导入自己的材料。

## 使用

在部署完成的站点登录，选择题库、练习范围和模式，准备会话并按页面提示在 ChatGPT 语音对话中使用插件。题库和练习记录存于该站点自己的数据库。删除个人题库或会话前请确认，删除会话会删除其回答和报告。

## 开发与部署

需要 Node.js 22.13.0 或更高版本。先将 `templates/hosting.json` 复制到 `.openai/hosting.json`；`npm run install:ci` 安装依赖；`npm run dev` 启动本地开发服务；`npm run lint` 和 `npm run build` 检查和构建。部署需要 Sites 的身份认证、D1 数据库与 MCP 能力，具体步骤见 [AGENTS.md](AGENTS.md)。本地预览不等于实际的 ChatGPT 语音或授权环境。

| 路径 | 用途 |
| --- | --- |
| `app/` | 网页、MCP 路由、口语练习逻辑和内置题库 |
| `db/`、`drizzle/` | D1 数据库结构与迁移 |
| `worker/` | 站点 Worker 入口 |
| `templates/hosting.json` | 无站点身份信息的部署配置模板 |
| `tests/` | 练习计划、题库导入和报告的测试 |
| `AGENTS.md` | 部署助手工作流程 |

本项目为独立练习工具，与 IELTS 官方无关联。
